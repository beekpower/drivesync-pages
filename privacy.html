Privacy policy

drivesync · last updated October 26, 2026

What data drivesync accesses

With the owner's permission (Google scope https://www.googleapis.com/auth/drive), drivesync reads and writes files in the owner's own Google Drive in order to keep them in sync with a folder on the owner's own computer or server.

How the data is used and stored

  • File contents and metadata are transferred only between Google Drive and the owner's own machine.
  • The OAuth token and a local index of file metadata are stored only on that machine.
  • No data is sent to the developer or to any third party, and nothing is used for advertising, analytics or model training.
  • drivesync is used only by its owner; it does not access anyone else's account.

Google API Services User Data Policy

drivesync's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the drivesync folder and its state directory on the owner's machine removes all locally stored data.
